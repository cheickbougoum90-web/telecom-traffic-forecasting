# Données

Source : Telecom Italia Big Data Challenge, jeu « Telecommunications, SMS, Call, Internet, MI »
(Harvard Dataverse, DOI 10.7910/DVN/EGZHFV). Activité issue des CDR, agrégée par cellule d'une grille
de 100 x 100 sur Milan, par pas de 10 minutes, de novembre à décembre 2013.

Les valeurs sont proportionnelles au trafic réel (facteur d'échelle gardé secret par l'opérateur) :
on prévoit donc une activité relative, pas des Mo.

Téléchargement manuel : placer les fichiers journaliers dans data/raw/.
